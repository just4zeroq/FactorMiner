# Promotion gate 阳性对照 / 统计校准报告

> **这份报告证明的是闸门统计校准，不是「挖到了 alpha」。** 所有面板来自已知强度的半合成 DGP；真实因子 IC 尾部更厚、自相关更强，因此下面的检出率是真实场景的**上界**。它不能替代一次干净的时间 OOS。

## 方法

面板 DGP：`R = vol · (market_frac · market[t] + ρ · z_F + √(1−ρ²) · ε)`，`ρ` 即已知真实 IC；样本内 / 样本外为同一 DGP 的独立抽样。
每个候选的 `hac_t`、`p_value`、`cost_adj_return`、`ls_t`、`sr`、`RankIC_oos`、`null_tstats` 全部经生产函数计算，再交给真实的 `apply_promotion_gates`，不手工填数。历史假设族用 `Uniform(0,1)` 的零 p 值补齐，使 BH-FDR 与 DSR 分母按 `n_trials` 真实放大。

- 样本内 641 bars × 20 assets，样本外 181 bars
- 往返成本 0.0018/单位换手，分位 20%，置换 30 次，每格 12 次重复
- 闸门：`empirical_p_max=0.05`，`dsr_min=0.9`，`fdr_max=0.05`，`oos_rankic_min=0.02`

## 解读边界

- ρ = 0 的高放行率才叫虚警；本闸门含成本正性 + 经验零分布，虚警率天然被压得很低，代价是**功效也可能被压没**。
- MDE 随 `n_trials` 上升是 DSR 的设计意图（搜索越多、门槛越高），但若 MDE 已高于加密日频因子文献中常见的真实 IC（约 0.02–0.05），则「0 promoted」不能再简单归因为「因子都不行」。
- 样本外段与样本内段共享同一 DGP，等于假设信号完全持久；这是对本方法最有利的情形，真实衰减只会更差。
- 本报告**不触碰**一次性 strict holdout 账本，也不构成正向 OOS 证据。
