# 因子挖掘：概念、算法、原理与工程实践

## 从信号假设到可证伪的 Alpha —— 基于 FactorMiner 与 20+ 开源框架的源码级对照

---

> **一句话立场**：因子挖掘的难点从来不是「能不能生成足够多的公式」，而是「能不能诚实地证明某一个公式不是运气」。本书用一半篇幅讲搜索与表示，用另一半篇幅讲证伪与纪律，因为后者才决定前者有没有价值。

---

## 内容提要

这是一本关于**自动化因子挖掘**的技术书。它不只讲「因子是什么」，而是把一条完整的研究链路拆开：

1. **概念层**：因子、Alpha、风险暴露、截面打分、前瞻收益、研究结论的等级；
2. **表示层**：算子、终端、AST / RPN / 源码 / 张量四种表达式形态，以及它们各自的搜索与执行代价；
3. **算法层**：先给出六种常见范式（手工规则、遗传规划、深度网络、强化学习、大语言模型、稀疏统计）的谱系与选型，再依次展开表达式语言、公式库与四种自动范式，六种产生候选的方式；
4. **评价层**：IC / RankIC / ICIR / 分位收益 / 换手 / 覆盖率的精确口径，以及 fitness 如何把多个指标压成一个可优化标量；
5. **证伪层**：多重检验、Newey–West HAC、BH-FDR / Holm、随机零分布、Deflated Sharpe Ratio、晋升闸门、purge / embargo、逐折重拟合的 walk-forward、一次性留出账本、阳性对照与统计功效；
6. **组合与执行层**：去重、mutual-IC 因子池、权重拟合、事件驱动回测、成本恒等式与真实资金费；
7. **工程层**：统一中间体抽象、Director 调度、异构存储、沙盒、实验 manifest、八阶段流水线、可复现性验证；
8. **行业层**：20+ 个开源框架的源码级横向矩阵、成熟度 × 加密货币适配度象限、十八条反面模式。

全书所有实现细节都对应到 `FactorMiner` 仓库中的真实文件与行号；所有竞品结论都来自项目内已有的源码实读报告，而不是 README 宣称。书中大量引用**失败的实验结果**——严格样本外含成本 −6.40%、验证段 −4.43%、84 个存量因子全库重审 0 通过——因为一个能诚实证伪自己的系统，比多 20 个算子更有教学价值。

## 本书的三个特点

**第一，把「打分」和「证伪」分开讲。** 多数资料把 IC 当作终点。本书用整整一篇说明：IC 是相关性的描述，不是显著性的判定，更不是可交易性的证明。搜索得越猛，越需要多重检验折减；`num_trials` 这个分母，就是结论的一部分。

**第二，竞品对比到源码行号。** 全书涉及的 qlib、RD-Agent、gplearn、gpquant、AlphaGen、AlphaForge、AlphaMaster、crypto-factor-lab、LLM-Alpha-Mining-Framework、alphalens、KunQuant-rs 等框架，其能力判断都基于 `docs/research/` 下的三份源码实读报告。凡 README 与实现不符处（例如 AlphaMaster 文件头注释的 fitness 权重与实际代码不一致、其 walk-forward 有折无重拟合），书中显式标注。

**第三，工程细节不停留在概念。** 你会看到 `evaluate_ast` 如何把 `op/left/right` 之外的键当作 kwargs 转发、`_target_for_shift` 为什么必须把尾部 shift 行置 NaN、`fit_linear_combination` 何时退化等权、以及一个「6 币预留池下 0 交易却报成功」的静默错误是怎么被发现和修掉的。这些才是研究系统真正会咬人的地方。

## 读者对象与预备知识

- **量化研究员 / 因子工程师**：想系统理解自动挖掘的算法谱系，并知道每条路线的失败模式。
- **平台开发者**：要设计或维护一套多范式研究系统，关心抽象、契约、可复现与统计闸门如何接线。
- **有编程基础的研究者**：只需 Python（pandas / numpy 层面）与基础统计（相关、t 检验、p 值）。不要求熟悉 PyTorch，也不要求读过资产定价论文。

## 术语与记号约定

| 记号 | 含义 |
| --- | --- |
| `F_t` / `f_{t,i}` | 时刻 `t` 的因子打分（截面时为资产 `i` 上的分量） |
| `R_{t+1}` / `r_{t+1,i}` | 从 `t` 之后入场、持有到未来某根 bar 的前瞻收益 |
| `IC_t` / `RankIC_t` | 时刻 `t` 截面上因子与前瞻收益的 Pearson / Spearman 相关 |
| `n_trials` | 累计评估过的候选总数，多重检验的试验次数分母 |
| `h` / `horizon_bars` | 标签的前瞻 bar 数，决定 purge 宽度 |
| `q` | 分位多空组合的分位比例（默认 0.20，即前后各 20%） |
| `w` | 因子池中各成员的权重向量 |
| `sr` | 每期净 Sharpe（`cost_adj_return / std_return`），非年化、非 IC-IR |

统一译名：净化（purge）、禁运期（embargo）、留出（holdout）、预注册（pre-registration）、晋升闸门（promotion gate）、试验次数（num_trials）、面值相关性（value correlation）、通道物化（channel materialization）、前瞻收益（forward return）、时间可用性（point-in-time）。
