## 第 4 章 因子挖掘算法谱系总览：范式小结卡与选型

> 本章回答：因子挖掘领域到底有哪几种"找公式"的打法，每一种的**原理**是什么、具体**怎么工作**、产物长什么样、适合什么场景、又会在哪里翻车。我们把十一种范式逐一做成"范式小结卡"，其中遗传规划（GP）、强化学习（RL）、神经网络（NN）、大语言模型（LLM）四种是主流自动挖掘范式，后面有专章深读；其余七种——手工规则、确定性枚举、稀疏统计、对抗生成、蒙特卡洛树搜索、聚类集成、贝叶斯优化——在此一并讲清。读完本章，你应当能对一个新框架先归类、再预判它的优缺点。

### 4.1 范式与框架：先分清两层

讨论"算法"之前，必须分开两个常被混用的词。

**框架（framework）** 是一份具体的工程实现：它有自己的算子清单、数据接口、默认参数和打包方式。qlib、RD-Agent、gplearn、AlphaGen、AlphaMaster、AlphaForge、FactorMiner 都是框架。同一个框架里往往塞进了不止一种范式——例如 AlphaForge 用 GAN 做主力生成器，同时把 gplearn、MaskablePPO 当作对照 baseline；FactorMiner 一个包里就同时装着 GP、RL、LLM、NN 四条生成路径。

**范式（paradigm）** 是对"因子从哪里来"这一根本问题的回答方式，与具体代码无关。它决定三件事：候选以什么数学对象表示（一棵树？一段代码？一组权重？）、靠什么信号更新（适应度排序？策略梯度？反向传播？还是上下文反思？）、以及最怕哪种失败（膨胀？奖励作弊？数据泄漏？）。范式是稳定的，框架是流水的；一个范式可被十几个框架各自实现，框架兴衰不改范式本身的功过。

本章把算法收敛到**十一种范式**。它们在本书中的地位并不相同，先给一张地图：

| 层级 | 范式 | 本书位置 |
| --- | --- | --- |
| 主力自动范式（专章深读） | 遗传规划 GP、强化学习 RL、大语言模型 LLM、神经网络 NN | 第 7–10 章 |
| 基础与对照范式（讲清定位） | 手工规则与公式库、经典统计与稀疏方法 | 第 6 章 / 基线对照 |
| 补充范式（本章讲清） | 确定性枚举、对抗生成 GAN、蒙特卡洛树搜索、聚类与集成选择、贝叶斯优化 | 本章 4.3 |

**证据层级的诚实声明**：下面每张小结卡里，凡标 `【源码实证】` 的框架细节都来自项目内 `docs/research/` 的源码实读报告；凡标 `【学界常见】` 的，是该领域通用方法，但在本次调研的 20+ 框架中**未作为主力范式出现**，故只讲原理与工作方式，不虚构某框架的具体实现。这个区分贯穿全书。

理解这些范式的关键，是抓住两条主轴。第一条是**驱动方式**：因子来自研究者的经济直觉（假设驱动），还是来自对数据的自动扫描（数据驱动）。第二条是**表示形式**：因子是一个人能读的公式（符号），还是只有前向传播能算的黑盒（亚符号）。这两条轴几乎预言了每种范式 80% 的优缺点。

### 4.2 四大主力自动范式：逐张小结卡

这一节是全书四种主力挖掘范式的"浓缩卡片"。每张卡按同一模板组织：**定位 → 原理 → 工作方式 → 产物与信号 → 代表框架 → 优势与陷阱 → 一句话小结**。想要公式推导与源码细节的读者，按卡末指引读第 7–10 章。

#### 4.2.1 遗传规划（GP）：把公式当作个体来演化

**定位**。把"找因子"改写为在表达式树空间上的随机搜索：一棵由算子与行情字段组成的抽象语法树（AST）就是一个候选，适应度引导选择、交叉、变异，种群逐代演化。

**原理**。设算子集 F（每个带元数 arity 1 或 2）、终端集 T（行情字段与临时常数），一棵合法树递归定义为：叶子取自 T，内部节点取自 F 且子节点数等于 arity，根的输出即因子面值。搜索空间由 Catalan 数量级给出，深度 d=4 时已远超可枚举范围，所以 GP 只能是"带选择压力的随机游走"：

```
f       = Eval(tree, X)                    # tree: AST，X: 行情面板
RankIC  = (1/T) · Σ_t spearman(f_t, r_{t+1})
fitness = Φ(RankIC, RankIC_oos, coverage, turnover, …)
adjusted = fitness / (1 + parsimony · depth)   # 简约压力，FactorMiner parsimony=0.05
```

GP 只用 Φ 的**序关系**（谁更大），不要求可导——这是它能处理离散、变长公式的根本原因。锦标赛选择的概率有闭式解：按 fitness 降序排名为 i 的个体，在规模 k 的锦标赛中胜出概率为 `[C(N−i+1,k) − C(N−i,k)] / C(N,k)`，直接给出"小种群必须配小 k"的调参依据。

**工作方式**（一次 GP 挖掘的完整循环）：

1. **初始化**：用 grow / full / half-and-half 生成 N 棵合法树，深度限制 2–6；临时常数由 uniform(−2,2) 之类分布抽取。
2. **评价**：对每棵树算 AST 得到因子面值 f，再算 RankIC、覆盖率、换手、成本净收益，合成 fitness。
3. **选择**：做 N 次锦标赛，每次随机抽 k 个个体，取其中 fitness 最高者获得繁殖资格。
4. **繁殖**：按概率执行子树交叉、点变异、子树变异、hoist 变异（缩短树高以控制膨胀）、复制。
5. **精英保留**：把最优若干棵原样带入下一代——不写回种群就会"任务成功但零产物"。
6. **去重与记账**：源码 MD5 硬去重 + 面值相关性软去重；每评估一个候选，`num_trials += 1`。
7. **终止**：达到代数上限或 fitness 停滞，输出 `state.population` 中的优秀个体。

**产物与信号**：可读的 AST 公式；优化信号是离散适应度的序关系（无梯度）。

**代表框架** `【源码实证】`：gplearn（默认种群 1000 / 20 代 / 锦标赛 20 / 初始深度 2–6，17 内置 + 5 保护算子，`parsimony_coefficient='auto'`）；gpquant（约 60 算子，fitness 直接用回测 Sharpe，固定 `[:400]/[400:800]` 单次切分）；AlphaGen 的 GP baseline；FactorMiner GP（种群 20 / 最大深度 4 / 锦标赛 k=3 / 交叉 0.8 / 变异 0.3 / 精英 2，`crypto_seed_ratio=0.3`）。

**优势与陷阱**：产物可读、无需梯度、对算子集友好；但必然面对表达式膨胀、每次评估都是一次独立假设检验（放大多重检验分母）、以及常数/全零因子在相关性下产生虚高的坑。

> **一句话小结**：GP 是"在公式语法树上的达尔文式搜索"——用锦标赛和变异代替梯度，代价是膨胀与试验次数爆炸。深读第 7 章。

#### 4.2.2 强化学习（RL）：把因子构造建模为序列决策

**定位**。把"写一条公式"建模成马尔可夫决策过程（MDP）：状态是已生成的表达式前缀（RPN 栈），动作是选一个算子 / 终端 / 窗口 / 停止符，奖励是整条轨迹终止时的一次性因子评价。

**原理**。目标与策略梯度是整套方法的地基：

```
J(θ)  = E_{τ~π_θ}[ R(τ) ]                         # 期望回报
∇J(θ) = E_τ[ R(τ) · Σ_t ∇log π_θ(a_t|s_t) ]       # log-derivative trick
∇J(θ) = E_τ[ Σ_t ∇log π_θ(a_t|s_t) · (R − b) ]    # 加 baseline b，只减方差不改期望
J'(θ) = J(θ) + β·H(π_θ),  H = −Σ_a π log π        # 熵正则防坍缩
```

与 GP 的本质差别：GP 是**无模型演化**，直接在个体上选择，没有跨代参数记忆；RL 是**可学习的生成分布**，把"什么结构值得生成"压缩进参数 θ，用梯度整体平移采样分布。采用 softmax 参数化时，两个闭式梯度反复出现：`∇_z log π(a|s) = e_a − p`（one-hot 减概率向量）、`∂H/∂z_a ∝ −p_a(log p_a + 1)`。

**工作方式**（一次 RL 训练 + 采样循环）：

1. **定义 MDP**：状态 = 当前栈/前缀；动作 = 词表中的 token；转移由栈的弹压规则确定（确定性）；终止时折叠成 AST。
2. **动作掩码**：把违反栈深约束（`delta = 1 − arity`）、剩余步数无法归约到 1 的非法位 logits 置为 `−1e8/−1e9`，使采样天然合法。
3. **采样轨迹**：按 `π_θ` 逐 token 采样 L 步，得到公式 τ，执行后得奖励 R(τ)。
4. **计算优势**：`advantages = reward − mean(rewards)`（batch baseline），降低梯度方差。
5. **策略更新**：REINFORCE 用 `grad_log p = one_hot − p` 累加 `advantage · grad_log p`，再加熵梯度，logits clip 到 ±20 防溢出。
6. **出样**：轨迹是训练产物；把每条轨迹折叠成的 AST 表达式连同指标写入 `state.population`，才是研究产物。

**产物与信号**：采样分布参数 θ（训练产物）+ 一批带指标的 AST 表达式（研究产物）；优化信号是奖励的似然比梯度。

**代表框架** `【源码实证】`：AlphaGen（MaskablePPO + LSTM/Transformer 策略网络，reward 是加入 AlphaPool 后的组合增量 `new_obj`，`loss = wᵀMw − 2wᵀc + 1 + α‖w‖₁`，α=5e-3，mutual IC>0.99 拒收）；AlphaMaster（REINFORCE + LoopedTransformer + 8 token 定长序列 + Top-60 精英堆 + island）；FactorMiner RL（纯 NumPy 概率字典，无 PyTorch 依赖，traj_len 4 / lr 0.05 / entropy_coef 0.01 / batch 10，`get_source()` 返回 AST 而非动作序列）。

**优势与陷阱**：能学出"生成分布"、天然可做组合感知搜索；但成败系于两件事——**动作掩码**（没有它则大量非法候选浪费试验预算）与 **reward 口径**（直接优化回测收益几乎必然 reward hacking）。此外训练产物与可评分因子是两类东西，策略权重不等于因子。

> **一句话小结**：RL 是"学着写公式的生成分布"——关键从来不是 PPO 还是 REINFORCE，而是动作掩码与诚实的 reward。深读第 8 章。

#### 4.2.3 神经网络（NN）：端到端表征与通道因子

**定位**。放弃"可读公式"，把因子定义为某个可微网络的一个输出通道：输入标准化行情面板，网络在训练目标指引下用反向传播学出权重，再把某个隐藏通道冻结成独立因子（"通道物化"）。

**原理**。训练目标是 MSE 与 Pearson IC Loss 的联合：

```
L = (1 − α)·MSE(pred, y) + α·(1 − corr(pred, y))    # FactorMiner 教学模板 α 默认 0.7
channels   = tanh(X @ W1 + b1)                       # 隐藏通道
prediction = channels @ W2 + b2
gram  = W1ᵀW1;  off_diag = gram − diag(diag(gram))    # 通道去相关惩罚
dW1  += diversity · 4 · (W1 · off_diag)
```

为什么要直接优化 IC？因为 MSE 关心数值拟合，而交易只关心**秩序**（谁涨得多）；IC Loss 把优化目标对齐到截面秩相关。通道去相关惩罚则迫使不同隐藏通道学到互补信号，而不是挤在同一个方向上。

**工作方式**（一次 NN 因子挖掘）：

1. **构造张量**：把面板转成 `样本 × 特征` 的过去式特征矩阵（只能用当前及更早的数据），标签是前瞻收益。
2. **标准化**：在**训练段** fit scaler（mean/std），再应用到验证/测试段——全样本 fit 会泄漏。
3. **前向与损失**：算 channels 和 prediction，联合 MSE + IC Loss + L2 + Gram 去相关。
4. **反向传播**：梯度裁剪（clip 5.0），早停（patience 20），逐轮在样本外算 RankIC。
5. **通道物化**：选出样本外表现最好的隐藏通道 `channel_idx`，冻结其权重，导出 `.npz` 工件，产出一个独立因子 `FactorExpressionTensor(model_version_id, channel_idx)`。
6. **入池与跨轮保留**：按样本外 fitness 排名取 Top-K，跨轮保留全程最优，写入 `state.population`。

**产物与信号**：可序列化的模型工件 + 物化后的通道因子；优化信号是损失的梯度。

**代表框架** `【源码实证】`：AlphaForge（AAAI'25，GAN 生成器 + Conv Predictor + 可微掩码，predictor 用 `weighted_mse_loss` 减少真实 evaluate 次数，入池阈值 `ic>0.03 & icir>0.1`）；qlib 模型层（LSTM/Transformer/图网络，但无挖掘器）；FactorMiner NN（纯 NumPy MLP，He 初始化，MODEL_FORMAT `numpy_mlp_factor_v1`；真正 Miner 在 `user_workspace/custom_miners/my_custom_nn.py`，hidden_dim 8 / lr 0.01 / epochs 50 / diversity 1e-3 / top_k_factors 5）。

**优势与陷阱**：表达力最强、天然端到端；但黑盒不可解释、对样本量与非平稳极敏感，且必须守住硬边界——**网络权重不是因子，物化出的通道才是**；训练张量也不能直接当可保存因子。

> **一句话小结**：NN 是"用梯度学出一个黑盒表征、再冻结某个通道当因子"——最强也最难证伪，边界在通道物化。深读第 10 章。

#### 4.2.4 大语言模型（LLM）：假设→代码→反思闭环

**定位**。把因子构造变成"假设生成 → 写代码 → 沙盒执行 → 看指标 → 反思 → 下一轮"的闭环，用自然语言的常识与推理能力替代手工设计。

**原理**。LLM 范式没有参数更新——**更新的是上下文，不是权重**。它把历史成功/失败经验、可用字段语义、评价指标组装进提示词，让模型产出代码；沙盒执行后把结果再写回提示词，形成 few-shot 反馈：

```
prompt_t = system(字段语义) + few-shot(成功池 top-5, 失败池 top-5) + reflection(上轮失败原因)
code_t   = LLM(prompt_t) 经代码块抽取
factor_t = Sandbox.run(code_t)        # AST 白名单 + 资源限制
V_t      = evaluate(factor_t)         # IC / RankIC / 成本净收益
archive  ← (code_t, V_t);  prompt_{t+1} = prompt_t + reflection(V_t)
```

**工作方式**（一次 LLM 挖掘循环）：

1. **初始化**：注入可用字段清单与语义（FactorMiner 还注入 `CRYPTO_STREAM_SPECS.rationale`），限制 `latest_visible_year` 防模型"背诵"回测年份。
2. **生成**：模型产出 Python 因子代码；用 `prompt_hash = sha256(prompt)` 记录来源，抽取围栏代码块（fenced code block），附 provenance（generator/model/prompt_sha256/iteration）。
3. **校验与执行**：AST 白名单检查（禁 `_` 前缀、禁私有赋值、常数 ≤1e6、幂次 ≤6），必须在 multiprocessing spawn 子进程 + 墙钟超时内把结果赋给 `factor`；再校验索引对齐。
4. **评价与反思**：算指标，成功/失败 reflection 各留 100 条，取最近 5+5 组装下一轮 few-shot。
5. **出样**：`state.population = successful` 集合；正式档案只持久化 Prompt 的 SHA-256，完整提示词存于旁路 recorder。

**产物与信号**：一段可读的因子代码 + provenance；优化信号是自然语言反思与 few-shot 上下文更新（无梯度）。

**代表框架** `【源码实证】`：RD-Agent（微软，假设→规格→代码两段式 JSON，CoSTEER 单轮最多 10 次自纠错，SOTA 库 0.99 相关去重）；LLM-Alpha-Mining-Framework（文本 gate 在碰 DataFrame 前拒掉约 90%，anti-paraphrase 六层去重，18-niche MAP-Elites = horizon 3 × data family 3 × turnover 2）；CosmosAlpha（MCTS/UCT + Graph Flow + Pareto）；FactorMiner LLM（顺序 / cross_asset 双模式，batch_size 5，`RestrictedSandbox`）。

**优势与陷阱**：能把研究者直觉自动化、产物天然是可读代码；但最危险的不是"模型会不会写因子"，而是**训练数据覆盖回测年份的隐性泄漏**、幻觉代码、以及反思记忆把验证集指标回灌提示词。同 prompt 重复采样还会快速烧光 `num_trials`。外部 API 非确定，需旁路 recorder 做确定性回放。

> **一句话小结**：LLM 是"用反思记忆驱动代码生成的搜索"——更新的是上下文而非权重，成败在沙盒边界与防泄漏。深读第 9 章。

### 4.3 其他七种范式：逐张小结卡

这七种范式要么是所有研究的基线（手工、稀疏统计），要么在调研框架里以"主方法"或"组合层"身份真实存在（枚举、GAN、MCTS、聚类集成），要么是该领域常见但本次调研未作为主力范式出现的通用方法（贝叶斯优化）。每种同样给小结卡。

#### 4.3.1 手工规则与公式库

**定位**。研究者基于经济逻辑（动量、反转、流动性、估值偏离）手写一个打分函数，在见数据之前就定好。

**原理**。把经济假设直接翻译成一个确定性函数 `f(X) → 截面打分`，候选不由搜索产生，而由人脑假设驱动，因此选择偏差被先验假设吸收，不进入 `num_trials` 分母（前提是**真的**没反复试）。

**工作方式**：① 从经济逻辑提出假设；② 选字段与算子写成公式；③ 在样本外一次性验证；④ 若不成立，修订假设并**记入试验日志**；⑤ 与自动范式的结果做消融对照。

**产物与信号**：可读公式；无自动更新信号（人来更新）。

**代表框架** `【源码实证】`：WorldQuant 101 Formulaic Alphas（Kakushadze 2016，约 24 类算子拼成，含 `rank`、`ts_argmax`、`signed_power`、`decay_linear`、三元条件 `? :`、`adv{d}`）；qlib Alpha158 / Alpha360（声明式模板，Alpha360 = 6 字段 × 60 位移，Alpha158 = kbar + price + rolling 组 × 5 窗口）。

**优势与陷阱**：可解释、可预注册、过拟合风险天然最低；但覆盖率受人类想象力约束，市场结构切换时更新慢。它是**基线与消融材料，不是挖掘结果**。

> **一句话小结**：手工规则是"假设先行、验证在后"的范式——最诚实，但最慢；它是标尺，不是产量。深读第 6 章。

#### 4.3.2 确定性枚举与模板组合

**定位**。不搜索"公式结构"，而是把一组固定模板的参数（窗口、字段、组合方式）按网格展开，穷举出成百上千个候选。

**原理**。设模板集合 P、参数网格 G，候选集 = `{p(g) | p ∈ P, g ∈ G}`，规模是网格的笛卡尔积。它不做学习，靠**覆盖**换取发现：只要真实信号落在模板族里，枚举就不会漏。

**工作方式**：① 定义模板族（如 `ts_rank(field, window)`）；② 展开窗口 `(6,12,24,48)` 与字段集；③ 对每个候选算 IC/RankIC；④ 组合层做两两组合；⑤ 用 Spearman 相关去重（如阈值 0.75）；⑥ 上多重检验闸门。

**产物与信号**：一批参数化的固定公式；无学习信号，只有筛选。

**代表框架** `【源码实证】`：crypto-factor-lab（21-op DSL 的 AST 枚举 + 受约束 LLM 提议）；alpha-factor-mining-crypto（13 核心 + 40 多窗口 + 40 组合，去冗余 Spearman `corr_threshold=0.75`，`score = 0.7·|spread_ir| + 0.3·|ic_ir|`）。

**优势与陷阱**：实现简单、可复现、覆盖确定；但参数网格的组合爆炸**等于隐式多重检验**——枚举一万个候选却按一次检验报告，是最常见的统计谎言来源。

> **一句话小结**：枚举是"用覆盖换发现"的蛮力法——便宜可靠，但必须把候选总数老老实实记进 `num_trials`。

#### 4.3.3 经典统计与稀疏方法

**定位**。把因子视作对收益的横截面回归项，用惩罚与矩阵分解从大堆特征里挑出少数稳健因子。

**原理**。稀疏回归在 OLS 上加 L1/SCAD 惩罚，把不重要的系数压到零：

```
β̂ = argmin_β [ (1/2)‖y − Xβ‖² + λ·Ω(β) ]    # Ω = |β|₁ (Lasso) 或 SCAD
```

惩罚项同时是正则与"选择器"，因此天然对多重检验友好；PCA/ICA 则从异象矩阵里提取共同因子作为降维表示。

**工作方式**：① 收集大特征池（因子动物园）；② 标准化后做 LassoCV / RidgeCV / 弹性网；③ 保留非零系数特征；④ 用 Fama–MacBeth 两阶段估计风险溢价与 t 值；⑤ 用 Newey–West 修正序列相关。

**产物与信号**：稀疏线性组合的系数；优化信号是带惩罚的损失梯度或闭式解。

**代表框架** `【源码实证】`：`alpha-factor-mining-crypto` 的 `regularized_optimize`（LassoCV/RidgeCV）与 `cluster_select`（层次聚类）；AlphaForge-Crypto 的 ICWeighted / Ridge / OptimalShrinkage(Ledoit-Wolf) 组合；FactorMiner 的岭回归组合（`λ=1.0`，`min_obs=60`，异常退化等权）。

**优势与陷阱**：方差低、结论稳健、最易通过统计审查；但表达力受限于线性与预设特征池，难以捕捉 GP/NN 能找到的非线性。

> **一句话小结**：稀疏统计是"用惩罚代替搜索"的稳健派——不惊艳，却最难被证伪推翻，是所有自动范式的计量基座。

#### 4.3.4 对抗生成（GAN）

**定位**。用一个生成器网络直接产出因子表达式的 token 序列，用一个判别/预测网络给候选打分，两者对抗训练。

**原理**。生成器 `G(z)` 把随机噪声 `z∈ℝ¹⁰⁰` 映射成表达式 logits，经可微掩码与 Gumbel-Softmax 采样成合法公式；预测器 `P` 用真实评价分数作标签学习"给公式打分"，从而**减少对昂贵的真实 evaluate 的调用次数**。生成器损失把"让预测器给高分"与多样性正则绑在一起：

```
loss_G = −mean(pred) + loss_simi + loss_potential    # 后者惩罚与已生成样本/隐空间过相似
```

**工作方式**：① 生成器输出 `(batch, 20, SIZE_ACTION)` logits；② 无参数掩码器把非法动作置 `−1e8`；③ `Gumbel-Softmax(hard=True)` 采样使离散采样可微；④ 预测器用 `weighted_mse_loss`（近期样本权重 2）+ 早停学习打分；⑤ 生成器按 −mean(pred) + 相似度惩罚更新；⑥ 把入池阈值达标的公式存入 zoo。

**产物与信号**：一批 token 序列公式；优化信号是预测器的可微代理分数（代理真实评价）。

**代表框架** `【源码实证】`：AlphaForge（AAAI'25 的**主方法**，DCGAN 生成器 + Conv Predictor，23 启用算子 / 窗口 `[1,5,10,20,30,40,50]`，`zoo_size=100`，入池阈值 `ic>0.03 & icir>0.1`，NaN>0.8 / 唯一值<0.01 / 与 zoo 相关过高置 0）。

**优势与陷阱**：生成器能学到复杂分布、代理预测器大幅降低 evaluate 成本；但引入 GAN 训练不稳定性，且预测器是"对真实指标的近似"——代理被优化过头就会与真实目标脱节。调研确认它**没有** FDR / Holm / purge 校正，防过拟合靠多段切分 + 早停 + 相关过滤。

> **一句话小结**：GAN 是"用可微代理模型给公式打分、反过来训练生成器"——快，但要警惕代理与真实评价的漂移。

#### 4.3.5 蒙特卡洛树搜索（MCTS）

**定位**。把表达式构造当作树搜索问题，用 UCT（Upper Confidence bound applied to Trees）在"探索新结构"与"利用已知好结构"之间平衡。

**原理**。每个节点是一个部分表达式，选择阶段用 UCT 值挑子节点：

```
UCT = mean_reward + c · sqrt( ln(N_parent) / N_child )    # c 控制探索强度
```

叶节点展开后做随机模拟（rollout）得到奖励，再沿路径反向传播更新访问数与奖励均值。与 GP 的"无记忆演化"不同，MCTS 显式维护一棵带统计量的搜索树。

**工作方式**：① 从根节点（空表达式）开始；② 按 UCT 选子节点直到叶；③ 展开叶节点的一个合法动作；④ rollout 出完整公式并评价；⑤ 反向传播奖励与访问数；⑥ 重复若干轮后取奖励最高的完整路径。

**产物与信号**：搜索树上的高分公式路径；优化信号是 rollout 奖励的反向传播。

**代表框架** `【源码实证】`：CosmosAlpha（MCTS/UCT + Graph Flow 效用传播 + 三维 Pareto 选择 `(|ric|, −std, top20)` + 类型化 DSL + LightGBM，`【学界常见】` 的 UCT 公式即其选择核心）。

**优势与陷阱**：能有系统地探索结构化空间、天然支持多目标 Pareto；但每次 rollout 都要评价公式，成本高， CosmosAlpha 同样**无独立 holdout / 无多重检验**，四个挖因子配置在同一窗口内评估选择扩散。

> **一句话小结**：MCTS 是"带记忆与探索/利用权衡的公式树搜索"——比 GP 更系统，但同样躲不过"搜索次数即检验次数"。

#### 4.3.6 聚类与集成选择

**定位**。不在"生成新公式"上下功夫，而在"已有因子池里挑谁、怎么加权"——把选择本身当作可优化的问题。

**原理**。用相关性/层次聚类把高度相似的因子分组，每组选代表，降低冗余；再用贪心前向或集成回归决定权重：

```
greedy_forward: 按 |IC_IR| 排序加入，要求 max_corr ≤ 0.7, min_ic_ir ≥ 0.3
combiner:       EqualWeight / ICWeighted / Ridge / LightGBM / OptimalShrinkage
```

**工作方式**：① 计算因子间相关矩阵；② 层次聚类分组，组内按 IC_IR 选代表；③ 贪心前向加入不超相关阈值的因子；④ 用验证窗口拟合组合权重；⑤ 逐期（如 `shift=21`）用历史窗口重估权重。

**产物与信号**：一个因子子集 + 权重向量；优化信号是 IC_IR 或组合目标。

**代表框架** `【源码实证】`：`alpha-factor-mining-crypto` 的 `cluster_select` + `greedy_forward(max_corr=0.7, min_ic_ir=0.3, max_factors=15)`；AlphaForge-Crypto 的 5 种 combiner；AlphaForge 的逐日 `torch.linalg.lstsq` 动态组合（`shift=21`，只用历史窗口，明确的防前视设计）。

**优势与陷阱**：能显著改善组合层面的稳健性、降低因子冗余；但它**放大而非减少**上游搜索的选择偏差——网格扫描 `max_corr × min_ic_ir` 产出 12 组候选却未做多重检验校正，就是现成的反面例子。

> **一句话小结**：聚类集成是"把选择当优化"的组合范式——能把一堆公式收成一个组合，但绝不替你背统计责任。深读第 11 章。

#### 4.3.7 贝叶斯优化（超参/结构寻优）

**定位**。用贝叶斯推断指导"下一步该试哪个配置"，目标是用尽量少的评价次数找到最优超参或结构参数。 `【学界常见：本次调研的 20+ 框架未以其为挖掘主范式，此处讲通用原理】`

**原理**。维护一个代理模型（常用高斯过程）拟合"配置 → 目标值"的未知函数，并用采集函数决定下一个试验点：

```
EI(x) = E[ max(0, f(x) − f_best) ]      # Expected Improvement：期望改进
x_next = argmax_x EI(x)                  # 在"高均值"与"高不确定"之间平衡
```

高斯过程给出每个点的均值与方差，EI 自然实现探索/利用权衡；每观察一个新点，后验更新，再选下一点。

**工作方式**：① 定义搜索空间（窗口、深度、阈值、算子概率等）；② 随机采样若干初始点并评价；③ 用观测数据拟合高斯过程后验；④ 最大化 EI 选下一个配置；⑤ 评价并更新后验；⑥ 达预算后取最优配置。

**产物与信号**：一组最优超参/结构配置；优化信号是采集函数（基于代理模型的不确定性估计）。

**代表框架** `【学界常见】`：自动化机器学习（AutoML / HPO）领域的通用工具（如 Gaussian-process-based BO、TPE、SMAC）；在因子挖掘中，它更多作为**其他范式的内层加速器**——给 GP/NN 找更好的超参，而不是直接产出表达式。本次调研的框架中未见以其为生成主力的实例，故不列源码引用。

**优势与陷阱**：样本效率高于网格/随机搜索，适合"评价很贵"的场景；但代理模型本身有建模误差，且**每试一个配置仍是一次假设检验**——把 BO 用在回测目标上，若不记 `num_trials`，同样是过拟合温床。

> **一句话小结**：贝叶斯优化是"用代理模型聪明地试参数"——省评价次数，但不省统计责任；它是加速器，不是生成器。

### 4.5 用四个维度给范式分类

把总表转成可推理的坐标，更有用的是下面四个二分维度。每个范式都能在四维空间里定位，定位本身就能预判失败模式。

| 维度 | 一端 | 另一端 | 直觉 |
| --- | --- | --- | --- |
| 驱动方式 | 假设驱动（人定公式） | 数据驱动（自动扫描） | 谁先提出候选 |
| 表示形式 | 符号（可读公式） | 亚符号（网络/系数） | 产物人能不能读懂 |
| 优化方式 | 无梯度（演化/策略/枚举） | 梯度（反向传播/回归） | 用什么信号更新 |
| 搜索目标 | 单因子适应度 | 组合感知（池增益） | 优化的是个体还是组合 |

据此快速画像：手工规则 = 假设·符号·无梯度·单因子；GP = 数据·符号·无梯度·单因子；NN = 数据·亚符号·梯度·单因子；RL = 数据·符号·无梯度·可组合；LLM = 数据·神经符号·无梯度·单因子；GAN = 数据·符号·梯度（代理）·单因子；MCTS = 数据·符号·无梯度·单因子（可扩为多目标）；枚举 = 数据·符号·无学习·单因子；稀疏统计 = 数据·线性·闭式·组合；聚类集成 = 数据·系数·无梯度·组合；BO = 数据·配置·代理梯度·单因子。

注意"数据驱动"≠"不用脑子"——LLM 与 GP 恰恰把人类知识编码进了先验（提示词、算子集、初始化），区别只是这些知识何时、以何种形式进入搜索。

### 4.6 统一抽象：所有范式共享的挖掘骨架

尽管数学天差地别，十一种范式在系统层面共享同一副骨架。看清楚这副骨架，后面读任何框架都只是"生成器与更新器换了实现"。

```
输入：行情面板 X（时间戳 × 标的 × 字段），标签 r（前瞻收益），统计闸门 G
初始化：生成器参数 / 种群 / 提示词 / 搜索树 / 代理模型 = init()
循环 until 停止准则：
    候选 C = generate(参数)              # GP:采样AST / RL:采样轨迹 / LLM:采样代码
                                        # NN:前向通道 / GAN:生成器输出 / MCTS:树路径
                                        # 枚举:网格展开 / 聚类集成:选子集 / BO:采集函数选配置
    评价 V = evaluate(C, X, r)           # IC / RankIC / 分位收益 / 成本净收益
    闸门决策 promote? = G(V, num_trials) # 多重检验、HAC、FDR、零分布、DSR
    if promote?: 因子池 P = admit(C, V)
    参数 = update(参数, V, C)            # GP:选择交叉变异 / RL:策略梯度 / LLM:反思
                                        # NN:反向传播 / GAN:对抗 / MCTS:反传 / BO:后验更新
输出：通过闸门的因子池 P，及其全程可审计的试验次数 num_trials
```

这副骨架里，**生成**与**更新**是各范式真正分家的两格（第 5–10 章逐一替换），而**评价**与**闸门**是横切所有的通用层（第 3 章与第 12–14 章）。一个常见误解是把"生成器更强"当成"系统更强"——但骨架告诉我们：只要闸门不诚实，再花哨的生成器也只是在更快地生产 p-hacked 的因子。

### 4.7 选型决策：面对不同问题怎么选

没有"最好的范式"，只有"最适配当下约束的范式"。下面是一组按优先级递减的判断：

- **你已有强经济假设**（例如"低波动应该溢价"）→ 手工规则 / 公式库（第 6 章）。零搜索成本、最不容易翻车，也是后续自动挖掘的对照。
- **你要在广阔公式空间里广撒网找非线性** → 遗传规划（第 7 章）。产物可读、无需梯度；前提是接受膨胀控制与多重检验的额外工程。
- **你拥有海量面板、要端到端且不怕黑盒** → 神经网络（第 10 章）。高维非线性最强，但要守死"权重≠因子、通道物化才是因子"的边界。
- **你的目标本身是"找一个能改善组合的新成员"** → 强化学习或聚类集成选择（第 8 / 11 章）。让奖励对齐组合增量，而非单因子 IC。
- **你的假设以自然语言/常识形式存在** → 大语言模型（第 9 章）。最擅长把直觉变代码，但必配沙盒与严格闸门，并默认它是非确定的。
- **评价极贵、想少试几次** → 贝叶斯优化或 GAN 代理预测器。用代理模型省评价次数，但别把代理分数当成真实结论。
- **你想系统探索结构化空间、且目标不止一个** → MCTS + Pareto。要有独立的验证窗口兜底。
- **你需要稳健、可作为计量证据基座的结果** → 经典稀疏 / 线性方法。很少"惊艳"，却最难被证伪推翻。

实践中的高分组合往往是"**GP 探索 + NN 精炼 + 稀疏做基线 + 手工做对照 + 聚类集成收口**"，再用统一的评价与闸门层收口——这正是第 16 章端到端流水线要落实的事。

### 4.8 工程陷阱（范式层面）

1. **把"工具能跑"当成"方法有效"**：框架跑出漂亮的样本内 IC，不等于范式适合你的数据频率与标签；先问"它优化什么"，再问"它跑通没有"。
2. **范式越新越好**：LLM、GAN、MCTS 听起来先进，但在加密货币高频、小标的池、弱标签场景下，朴素 GP 加诚实闸门常常更稳。新颖度不是稳健度的代理。
3. **忽略数据频率对范式的约束**：GP 在小样本上靠搜索易过拟合；NN 在小样本上学不动；稀疏回归在低信噪比下系数全塌。选范式前先看 `bars × 标的` 量级。
4. **组合驱动搜索在小样本下退化为单因子**：AlphaGen 式"池增益"奖励需要足够多的池成员才有意义；池为空时它等价于单因子 IC，却仍按组合口径记账。
5. **代理优化脱离真实目标**：GAN 的预测器、BO 的高斯过程都是"对真实评价的近似"；代理被优化过头，线上的真实 IC 会与代理分数脱节——必须定期用真实 evaluate 校准。
6. **不同范式用不同 `num_trials` 分母却套同一闸门**：GP 是种群×代数，LLM 是采样次数（重复采样会悄悄烧光），枚举是网格规模，BO 是采集次数。闸门要按真实试验次数归一，否则 FDR 失去意义。

### 4.9 本章小结

1. 区分**范式**（对"因子从哪来"的回答）与**框架**（具体实现）；一个范式可被多个框架实现，框架兴衰不改范式功过。
2. 十一种范式可归两条主轴：**假设驱动 vs 数据驱动**、**符号 vs 亚符号**；四条分类维度（驱动/表示/优化/目标）能预判每种范式的失败模式。
3. **GP** 是语法树上的达尔文式搜索，产物可读但必过膨胀与多重检验两关；**RL** 是学出来的生成分布，关键在动作掩码与 reward 口径，不在 PPO/REINFORCE。
4. **NN** 用梯度学黑盒表征、冻结通道成因子，表达力最强但边界在通道物化；**LLM** 用反思记忆更新上下文（非权重），成败在沙盒与防泄漏。
5. 其余七种各有定位：手工规则是标尺、枚举用覆盖换发现、稀疏统计是稳健基座、GAN 用代理降成本、MCTS 做系统探索、聚类集成收口组合、贝叶斯优化省评价次数。
6. **所有范式共享"生成→评价→闸门→更新"骨架**；生成与更新是分家处，评价与闸门是通用层。生成器再强，闸门不诚实也只会更快地产出 p-hacked 因子。
7. **每一次候选评价都是一次假设检验**——无论来自演化、采样、网格还是采集函数。统一的 `num_trials` 记账是跨范式可比的唯一基础。
8. 选型看约束：强假设用手工、广撒网用 GP、端到端用 NN、组合感知用 RL/聚类、直觉自动化用 LLM、评价贵用 BO/GAN、稳健基座用稀疏；高分组合是多范式互补 + 统一闸门。
