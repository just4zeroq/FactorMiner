## 第 4 章 因子挖掘算法谱系总览：六种范式与选型

> 本章回答：在动手写任何一行挖掘代码之前，因子挖掘领域到底有哪些"常见打法"，它们各自的数学本质、代表工作和致命弱点是什么，以及面对一个新问题该先看哪一类文献。我们把后面六章要深挖的遗传规划、强化学习、大语言模型、神经网络与手工公式，连同稀疏回归、表征学习等"教材里常提但本书不单列"的方法，统一放进一张谱系图里，并给出一组可操作的选型判断。读完本章，你应当能在看到一个新框架时，先把它归到某一类范式，再预判它会在哪里翻车。

### 4.1 范式与框架：先分清两层

讨论"算法"之前，必须分开两个常被混用的词。

**框架（framework）** 是一份具体的工程实现：它有自己的算子清单、数据接口、默认参数和打包方式。qlib、RD-Agent、gplearn、AlphaGen、AlphaMaster、AlphaForge、FactorMiner 都是框架。同一个框架里往往塞进了不止一种范式——例如 qlib 既是算子与数据的"事实上标准"，又把自动挖掘外包给 RD-Agent；FactorMiner 一个包里就同时装着遗传规划、强化学习、大语言模型与神经网络四条生成路径。

**范式（paradigm）** 是对"因子从哪里来"这一根本问题的回答方式，与具体代码无关。它决定了：候选以什么数学对象表示（一棵树？一个网络权重？一段代码？）、靠什么信号引导搜索（适应度排序？梯度？奖励？）、以及最怕哪一种失败（膨胀？奖励作弊？泄漏？）。范式是稳定的，框架是流水的；一个范式可以被十几个框架各自实现，而一个框架的兴衰不改范式本身的功过。

本书把因子挖掘的算法收敛到**六个常见范式**。前五个在后续章节逐一深读，第六个（经典统计与稀疏方法）虽然本书不单列章节，却是几乎所有实证资产定价研究的基座，必须在此讲清其位置：

1. 手工规则与公式库（假设驱动 / 符号）
2. 遗传规划与符号回归（数据驱动 / 符号 / 无梯度）
3. 表征学习与深度网络（数据驱动 / 亚符号 / 梯度）
4. 强化学习（数据驱动 / 序列决策 / 策略梯度）
5. 大语言模型生成（数据驱动 / 神经-符号混合）
6. 经典统计与稀疏方法（数据驱动 / 线性 / 梯度或闭式）

理解这六者的关键，是抓住两条主轴。第一条是**驱动方式**：因子到底来自研究者的经济直觉（假设驱动），还是来自对数据的某种自动扫描（数据驱动）。第二条是**表示形式**：因子是一个人能读的公式（符号），还是一个只有前向传播能算的黑盒（亚符号）。这两条轴几乎预言了每种范式 80% 的优缺点。

### 4.2 六个常见范式逐一速写

#### 4.2.1 手工规则与公式库

这是最古老、也最不可替代的范式。研究者基于经济学逻辑（动量、反转、流动性、估值偏离）手写一个打分函数，例如 WorldQuant 公开的一百零一个公式化 Alpha（Kakushadze, 2016），它们由 `rank`、`ts_argmax`、`signed_power`、`decay_linear`、三元条件 `? :`、`adv{d}` 等约二十四类算子拼成。qlib 的 Alpha158 / Alpha360 则是"声明式模板"：把若干字段按时间位移铺开，自动生成数百个候选特征，本质仍是人工设计的特征工程。

它的核心优势是**可解释、可预注册、过拟合风险天然最低**——因为公式在见数据之前就写好了，选择偏差被先验假设吸收。致命弱点是**覆盖率受人类想象力上限约束**，且当市场结构切换时，人工规则的更新速度远慢于自动搜索。本书第 6 章专门讲它"不是挖掘结果，而是基线与消融材料"的定位。

#### 4.2.2 遗传规划与符号回归

遗传规划（Genetic Programming, GP）把"找因子"改写成在表达式树空间上的随机搜索：一棵由算子与行情字段组成的抽象语法树（AST）就是一个候选，适应度（通常是截面 RankIC 或其组合）引导选择、交叉、变异，种群逐代演化（Koza, 1992 奠基）。gplearn 是这一范式最普及的开源实现（默认种群 1000、迭代 20 代、锦标赛规模 20、初始深度 2–6）；gpquant 把它推向量化，用约 60 个算子、把 fitness 直接定为回测 Sharpe。

GP 的独特价值是**能发现人类没写过的非线性组合，且产物仍是可读公式**。但它有三道坎：表达式膨胀（bloat）、每一次评估都是一次独立假设检验（放大多重检验分母）、以及需要强闸门防止"公式越长越像过拟合"。本书第 7 章从树表示、闭包性质、锦标赛选择的概率推导一直讲到膨胀控制与真实陷阱。

#### 4.2.3 表征学习与深度网络

这条路线放弃"可读公式"，转而把因子定义为某个可微网络的一个输出通道：输入是标准化后的行情面板，网络在训练目标（MSE、或直接与标签相关系数最大化的 IC Loss）指引下用反向传播学出一组权重，再把某个隐藏通道冻结成一个因子（"通道物化"）。AlphaForge（AAAI'25）用 DCGAN 式生成器生产因子、用卷积预测器打分；qlib 的模型层（LSTM、Transformer、图网络）也属于这一类，只是它把"自动挖掘器"留给了外部。

优势是**能捕捉高维非线性与跨标的复杂模式，且天然端到端**。代价是黑盒不可解释、对样本量与非平稳极其敏感、训练产物与"可直接评分的因子"之间存在一道必须讲清的边界（权重本身不是因子，物化出的通道才是）。本书第 10 章展开。

#### 4.2.4 强化学习

强化学习（RL）把"构造一条公式"建模成马尔可夫决策过程：状态是已生成的表达式前缀（或 RPN 栈），动作是从词表里选一个算子 / 终端 / 窗口 / 停止符，奖励是整条轨迹终止时的一次性因子评价。与 GP 的本质区别在于：GP 是**无模型演化**，直接在个体上做选择；RL 是**可学习的生成分布**，把"什么样的结构值得生成"压缩进参数 θ，用策略梯度整体平移采样分布。AlphaGen 用 MaskablePPO + LSTM/Transformer 生成公式并即时喂入 AlphaPool；AlphaMaster 用 REINFORCE + 循环 Transformer + 定长 token 序列，配 Top-60 精英堆与 island 策略。

RL 能天然做**组合感知搜索**（奖励可定义为"加入因子池后的组合增益"），但极度依赖两件事：把非法动作挡在外的**动作掩码**，以及 reward 口径的设计——直接优化回测收益几乎必然 reward hacking。本书第 8 章讲透"RL 挖因子的关键不是 PPO，是 masking"。

#### 4.2.5 大语言模型生成

大语言模型（LLM）把因子构造变成"假设→代码→执行→反思"的闭环：模型基于可用字段与少量成功/失败示例，写出一段计算因子的 Python 代码，沙盒执行后算指标，再把结果回灌提示词作为下一轮反思。RD-Agent 把这一过程拆成"假设生成→规格→代码"两段式，并配 CoSTEER 单轮最多十次自纠错；LLM-Alpha-Mining-Framework 在代码触碰数据前用文本闸门拒掉约九成候选，并用 18 个生态位（MAP-Elites）做多样性管理。

它的卖点是**能借用模型训练语料里的金融常识，把"研究者的直觉"自动化**，并能自然产出可读代码。最危险的不是"模型会不会写因子"，而是**训练数据覆盖回测年份造成的隐性泄漏**、幻觉代码，以及"反思记忆把验证集指标回灌提示词"这类温和但致命的违规。本书第 9 章细讲沙盒边界与统计闸门。

#### 4.2.6 经典统计与稀疏方法

这一支不属于"自动挖掘新因子"的热门叙事，却是整个领域的计量基座，必须在此点名。它把因子视作对收益的横截面回归项：用 Lasso / SCAD / 弹性网在成百上千个候选特征上做**稀疏线性回归**，靠惩罚项而非搜索来挑出少数几个有解释力的因子；用 PCA / ICA 从大量异象中提取**共同因子**；用 Granger 因果、贝叶斯层次模型做因果与不确定性推断。Fama–MacBeth 两阶段回归、因子动物园（factor zoo）的稀疏化，都归在此类。

它的优点是**方差低、结论稳健、对多重检验友好（惩罚即正则）**，缺点是表达力受限于线性与预设特征池，难以捕捉 GP/NN 能找到的复杂非线性。在本书中，它主要作为"基线对照"与"组合层降维（岭回归权重）"出现，不单列章节，但读者应清楚它始终在场。

### 4.4 用四个维度给范式分类

把表 4.3 转成可推理的坐标，更有用的是下面四个二分维度。每个范式都能在四维空间里定位，定位本身就能预判它的失败模式。

| 维度 | 一端 | 另一端 | 直觉 |
| --- | --- | --- | --- |
| 驱动方式 | 假设驱动（人定公式） | 数据驱动（自动扫描） | 谁先提出候选 |
| 表示形式 | 符号（可读公式） | 亚符号（网络/系数） | 产物人能不能读懂 |
| 优化方式 | 无梯度（演化/策略/枚举） | 梯度（反向传播/回归） | 用什么信号更新 |
| 搜索目标 | 单因子适应度 | 组合感知（池增益） | 优化的是个体还是组合 |

据此可快速画像：手工规则 = 假设·符号·无梯度·单因子；GP = 数据·符号·无梯度·单因子；NN = 数据·亚符号·梯度·单因子（除非专门做组合）；RL = 数据·符号·无梯度·可组合；LLM = 数据·神经符号·无梯度·单因子；稀疏回归 = 数据·线性·梯度或闭式·单因子（但输出已是稀疏组合）。注意"数据驱动"≠"不用脑子"——LLM 与 GP 恰恰把人类知识编码进了先验（提示词、算子集、初始化），区别只是这些知识何时、以何种形式进入搜索。

### 4.5 统一抽象：所有范式共享的挖掘骨架

尽管数学天差地别，六种范式在系统层面共享同一副骨架。看清楚这副骨架，后面读任何框架都只是"生成器与更新器换了实现"。

```
输入：行情面板 X（时间戳 × 标的 × 字段），标签 r（前瞻收益），统计闸门 G
初始化：生成器参数/种群/提示词 = init()
循环 until 停止准则：
    候选 C = generate(参数)              # GP:采样AST / RL:采样轨迹 / LLM:采样代码 / NN:前向通道
    评价 V = evaluate(C, X, r)           # IC / RankIC / 分位收益 / 成本净收益
    闸门决策 promote? = G(V, num_trials) # 多重检验、HAC、FDR、零分布、DSR
    if promote?: 因子池 P = admit(C, V)
    参数 = update(参数, V, C)            # GP:选择交叉变异 / RL:策略梯度 / LLM:反思 / NN:反向传播
输出：通过闸门的因子池 P，及其全程可审计的试验次数 num_trials
```

这副骨架里，**生成**与**更新**是各范式真正分家的两格（第 5–10 章逐一替换），而**评价**与**闸门**是横切所有的通用层（第 3 章与第 12–14 章）。一个常见误解是把"生成器更强"当成"系统更强"——但骨架告诉我们：只要闸门不诚实，再花哨的生成器也只是在更快地生产 p-hacked 的因子。

### 4.6 选型决策：面对不同问题怎么选

没有"最好的范式"，只有"最适配当下约束的范式"。下面是一组可操作的判断，按优先级递减：

- **你已有强经济假设**（例如"低波动应该溢价"）→ 先用手工规则/公式库落地基线（第 6 章）。它是零搜索成本、最不容易翻车的起点，也能作为后续自动挖掘的对照。
- **你要在广阔公式空间里广撒网找非线性** → 遗传规划（第 7 章）。它产物可读、无需梯度、对算子集友好；前提是接受膨胀控制与多重检验的额外工程。
- **你拥有海量面板、要端到端且不怕黑盒** → 表征学习/深度网络（第 10 章）。它在高维非线性上最强，但要把"权重≠因子、训练张量≠可保存因子"的边界守死，并准备应对非平稳。
- **你的目标本身就是"找一个能改善组合的新成员"** → 强化学习或组合感知搜索（第 8 章）。让它优化"加入池后的组合增益"而非单因子 IC，但要配齐动作掩码与诚实 reward。
- **你的假设以自然语言/常识形式存在，且想自动化研究过程** → 大语言模型（第 9 章）。它最擅长把直觉变代码，但必须配沙盒与严格闸门，并默认它是非确定的。
- **你需要稳健、低方差、可作为计量证据基座的结果** → 经典稀疏/线性方法（基线对照）。它很少"惊艳"，却最难被证伪推翻。

实践中的高分组合往往是"**GP 探索 + NN 精炼 + 稀疏做基线 + 手工做对照**"，再用统一的评价与闸门层收口——这正是第 16 章端到端流水线要落实的事。

### 4.7 工程陷阱（选型层面）

1. **把"工具能跑"当成"方法有效"**：一个框架跑出漂亮的样本内 IC，不等于它的范式适合你的数据频率与标签定义；先问"它优化的是什么"，再问"它跑通了没有"。
2. **范式越新越好**：LLM 与 RL 听起来先进，但在加密货币高频、小标的池、弱标签场景下，朴素 GP 加诚实闸门常常更稳。新颖度不是稳健度的代理。
3. **忽略数据频率对范式的约束**：GP 在小样本上靠搜索易过拟合；NN 在小样本上根本学不动；稀疏回归在低信噪比下系数全塌。选范式前先看你的 `bars × 标的` 量级。
4. **组合驱动搜索在小样本下退化为单因子**：AlphaGen 式"池增益"奖励需要足够多的池成员才有意义；池为空时它等价于单因子 IC，却仍按组合口径记账，制造虚假的"组合感知"。
5. **给每个范式配同一套闸门，却用不同分母**：GP 的 `num_trials` 是种群×代数，LLM 的 `num_trials` 是采样次数（且易因重复采样悄悄烧光），NN 几乎无显式候选计数。闸门要按范式的真实试验次数归一，否则 FDR 失去意义。

### 4.8 本章小结

1. 区分**范式**（对"因子从哪来"的回答）与**框架**（具体实现）；一个范式可被多个框架实现，框架兴衰不改范式功过。
2. 六个常见范式可归两条主轴：**假设驱动 vs 数据驱动**、**符号 vs 亚符号**；这两条轴预言了大部分优缺点。
3. 手工规则可解释、可预注册、过拟合风险最低，但覆盖率受人类想象力约束；它是基线，不是挖掘结果。
4. 遗传规划产物可读、无需梯度，但必须直面膨胀、多重检验放大与强闸门三道坎。
5. 深度网络表达力最强却最黑盒、最怕非平稳；"网络权重不是因子，物化出的通道才是"是硬边界。
6. 强化学习的关键是**动作掩码**与 **reward 口径**，不是 PPO 与 REINFORCE 的选型；大语言模型的关键是**沙盒**与**防泄漏**，不是模型大小。
7. 所有范式共享"生成→评价→闸门→更新"的骨架；生成器再强，闸门不诚实也只会产生 p-hacked 因子。
8. 选型看约束：强假设用手工、广撒网用 GP、端到端用 NN、组合感知用 RL、直觉自动化用 LLM、稳健基座用稀疏；高分组合是"GP 探索 + NN 精炼 + 稀疏基线 + 手工对照 + 统一闸门"。
